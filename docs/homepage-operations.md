## 문의 메일

서버 전용 환경변수는 `.env.example`의 `CONTACT_RESEND_API_KEY`, `CONTACT_FROM_EMAIL`, `CONTACT_TO_EMAIL`이다. 키를 `NEXT_PUBLIC_` 변수나 저장소에 넣지 않는다.

문의가 전송되면 화면과 수신 메일에 같은 접수번호가 표시된다. Vercel 함수 로그에는 접수번호, 공급자 접수 ID, 상태만 남는다. 이름·이메일·문의 본문은 로그에 기록하지 않는다.

- `contact_delivery_accepted`: 메일 서비스가 수락한 상태다. 받은편지함 도착 보장은 아니다.
- `contact_delivery_failed`: 서비스가 접수를 거절했다. 메일 서비스 로그에서 상태를 확인한다.
- `contact_delivery_unconfirmed`: 네트워크 등으로 접수 결과를 확정하지 못했다. 동일 문의를 재시도하면 공급자의 중복 방지 키를 유지한다.

접수번호로 Vercel 로그를 찾고 메일 서비스의 접수 ID로 전달 상태를 확인한다. Gmail의 받은편지함·스팸함도 확인한다. 전달 거절·수신 실패가 지속되면 홈페이지의 전화·이메일 안내를 사용하고 전송 설정을 점검한다. 자동 회신이나 정기 메일 발송은 구현하지 않았다.

## 분석

- `generate_lead`: 공급자가 문의를 접수한 뒤 한 번 전송한다.
- `contact_open`: 홈페이지의 문의 링크 클릭.
- `contact_click`: 전화 또는 이메일 클릭. `contact_method`로 구분한다.
- `select_content`: 공식 LAB 개별 수행 사례 클릭. `content_type=case_study`.
- `profile_download`: 기관소개서 다운로드.

폼 입력값·이메일·전화번호·쿼리 문자열을 위 전용 이벤트의 매개변수에 넣지 않는다. 2026-11-04 대표 홈페이지의 GA4 속성 `532403688` / 측정 ID `G-56JBYD7D0Q`에서 `generate_lead`를 주요 이벤트로 지정했다. 코드로 전송한 이벤트를 사용하며 이벤트당 한 번 집계하고 기본 금액은 부여하지 않았다. 청년센터 속성은 변경하지 않았다. 실제 이용자의 수집 여부는 GA4 실시간·이벤트 보고서에서 확인한다. 전화·이메일 클릭은 문의 의향이며, 실제 상담 완료 건수와 구분한다.

## 실적과 자료

대표 사례의 결과는 공개 LAB 원문 링크로 연결한다. 집계 정의가 확인되지 않은 기관 전체 누적 수치 대신 공개된 대표사업 목록·심화 사례·전문 분야의 실제 개수를 표시한다. 누적 실적을 다시 게시하려면 실제 사업 기록의 기준일·집계 범위·중복 참여 집계 방식을 함께 확정한다. 기관소개서의 문구를 변경할 때는 PDF와 홈페이지의 내용이 일치하는지 확인한다.

## 확인한 운영 상태

2026-11-04 테스트 문의 한 건이 대표 Gmail의 받은편지함에 도착했고, 회신 주소와 SPF·DKIM·DMARC 인증을 확인했다. 테스트 문의 제목과 본문에 점검용임을 표시했다. 반복 테스트로 실제 문의나 전환을 부풀리지 않는다.

Google Search Console의 도메인 속성 `sc-domain:soilabcoop.kr`에서 대표 홈페이지 사이트맵이 성공 상태이고 홈페이지가 색인되어 있음을 확인했다. 네이버 소유 확인 메타 태그는 유지하며, 서치어드바이저 관리자 확인은 계정 로그인이 필요하다.
