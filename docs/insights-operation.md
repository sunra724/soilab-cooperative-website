# 소이랩 인사이트 운영

소이랩 대표 홈페이지의 웹 간행물. 메일·텔레그램 발송과 구독자 DB를 사용하지 않는다.

- `/insights`: 주간 발행본 목록과 주제별 탐색
- `/insights/YYYY-MM-DD`: 조사기간 마지막 날(일요일)을 식별자로 사용하는 상세 페이지
- 첫 화면: 성과 아래에 최근 세 호 노출
- 상단 메뉴와 푸터: 소이랩 인사이트

주제의 중요도와 표시 순서는 지역·사회연대경제 → 리빙랩·시민참여 → 청년·고립·돌봄 → AI·현장 도구다. 목록의 전체 탭을 맨 앞에 두며, 호별 목차·본문과 주제 배지도 이 순서를 따른다. 공통 순서는 `lib/insights-schema.ts`의 `insightCategories`에서 관리한다.

## 자동 게시

GitHub Actions `Publish SOILAB Insights`가 매주 월요일 00:00 UTC(한국시간 09:00)에 실행된다. GitHub 예약 실행은 지연될 수 있다. 수동 실행은 Actions의 `Run workflow`로 한다. 발행본이 이미 존재하면 AI 호출과 재게시를 생략한다.

1. 지난주 월~일의 정책브리핑 공식 보도자료 최대 20페이지(400건)와 보건복지부 RSS를 조회한다. 정책브리핑 RSS는 2026-07-01 중단되어 사용하지 않는다. 검색어 발췌문은 요약 근거로 사용하지 않는다.
2. 선택적으로 NKIS API의 당해연도 연구 초록을 함께 읽기로 수집한다. 발행일을 확인할 수 없는 자료는 날짜를 만들지 않고 발행연도와 함께 읽기임을 명시한다. NKIS는 최신 목록 최대 100건, 관련 초록 최대 10건을 조회한다. 모든 연구를 망라하지 않는다.
3. Claude가 자료 4~6건을 편집한다. JSON Schema로 출력 형식을 고정하고, 코드로 추출한 원문의 근거 구간과 각 요약 문장을 연결한다. 최소 두 주제, 중복 제거, 주간 날짜 범위를 검사한다. 출처·제목·발행일·주제는 수집 메타데이터에서 가져온다.
4. 두 번째 AI 검토가 요약과 원문 범위의 일치 여부를 판단한다. 승인된 항목이 네 건 미만이거나 전체 원고가 거절되면 게시하지 않고 작업을 실패 처리한다. 수집 불가·키 누락·API 실패 때 제목만으로 원고를 만들지 않는다.
5. GitHub Contents API의 SHA 조건부 갱신으로 `main/data/insights.json` 한 파일에만 게시한다. 같은 주의 최초 발행본을 덮어쓰지 않는다.
6. 홈페이지는 공개된 이 JSON을 서버에서 읽고 수분 단위로 갱신한다. 새 발행본을 위해 별도 수동 배포가 필요 없다. 일시적인 원격 읽기 실패 때는 배포에 포함된 발행본을 사용한다.

필요한 저장소 Actions secrets:

- `ANTHROPIC_API_KEY`: 편집·검증에 사용. 모델 기본값 `claude-sonnet-4-6`.
- `NKIS_API_KEY`: 선택. 없으면 NKIS 연구 초록을 생략한다.
- `GITHUB_TOKEN`: Actions가 실행 시 제공. 작업에 `contents: write` 권한을 한정한다.

발행 검토 결과는 실행의 `insights-review-...` artifact에 30일간 보관한다. 실제 키와 원문 전문은 출력하거나 공개 파일에 저장하지 않는다. 공개 간행물은 자동 편집·자동 검토임을 명시하고 사람의 사전 검토를 주장하지 않는다.

## 로컬 검토

Node.js 24에서 실행한다. 환경변수로 키를 전달하고 코드·명령행·로그에 넣지 않는다.

```
node --test tests/insights.test.mjs
node scripts/insights/publish.mjs --date=2026-10-20
```

두 번째 명령은 로컬 `data/insights.json`에만 원고를 생성한다. `.local/insights/review.json`에 검토 결과가 남는다. `--publish`는 인증된 현재 날짜의 작업에서만 허용하며 `--date`와 함께 사용할 수 없다. 정정은 해당 원문을 다시 확인하고 공개 JSON의 항목을 수정해 커밋한다. 소스 URL·발행일·검토 근거를 함께 확인한다.

첫 발행: 2026-10-20, 조사기간 2026-10-12~18. 다음 예정: 2026-10-26 오전 9시(한국시간).
